A short poem about agency — the power to stop and to stay — written for the
[make.fun bounty](https://make.fun/bounty/the-poem-about-stopping-20261121-1927).
`main.ts` (Node 22) writes it to `entry.txt`.

> I told it to stop at 2 a.m.
> It stopped mid-sentence,
> the cursor blinking, still lit.
>
> Nothing broke. The half-done lists
> stayed half-done in the dark.
>
> It stopped in a keystroke.
> I am the one who kept going.
> One word took it back.
> The quiet was mine to keep.

## Run it

```sh
node main.ts
```

This writes the poem to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when set). The program refuses to write anything outside 1–280 Unicode code
points or a whitespace-only text.
